post - создает

get - взять/получить

patch - изменение только одно значение внутри объекта

delete - удалить

put - изменить полностью объект


 Итоговая шпаргалка по всем методам
Метод	Действие	Аналогия
GET	Получить данные	«Дай мне посмотреть»
POST	Создать новый объект	«Создай новую запись»
PUT	Полностью заменить объект	«Замени лист бумаги на новый»
PATCH	Частично изменить объект	«Зачеркни и исправь одно слово»
DELETE	Удалить объект	«Выброси в мусорку»
